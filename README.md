# 蜘蛛侠桌面特效（Spiderman Desktop Effect）

一个 Windows 桌面小应用：全局监听键盘，输入 `mj` 后按回车，屏幕正上方弹出透明蜘蛛侠动画（带声音），约 2.8 秒自动消失。应用常驻，可反复触发；带控制窗口（特效开关），关闭窗口即退出。

## 使用

- **免安装**：从 Releases 下载 exe（解压后双击 `蜘蛛侠特效.exe` 即可），无需安装 Python
- **源码运行**：需要 Python 3，安装依赖 `pynput`、`pillow` 后运行 `桌面特效/蜘蛛侠桌面特效.pyw`

## 功能

- 输入 `mj` 后按**回车** → 蜘蛛侠从屏幕**正上方**播放（透明背景、置顶悬浮、带声音约 2.8 秒），播放完自动消失
- 无论触发多少次都会重播；播放中再触发会先清掉旧画面和声音，从头重播
- 控制窗口含"特效开关"按钮；关闭窗口即退出程序
- 输入 `stopmj` 后按回车 → 退出

## 目录
