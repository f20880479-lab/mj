# 🕷️ 蜘蛛侠桌面特效

**Spiderman Desktop Effect**

输入 `mj`，蜘蛛侠从天而降 🎉

</div>

---

✨ 一个有趣的 **Windows 桌面小应用**：全局监听键盘，输入 `mj` 后按回车，屏幕正上方弹出**透明蜘蛛侠动画**（带声音），播放完自动消失。应用常驻后台，可反复触发。

## 🎯 功能亮点

| 功能 | 说明 |
| :--- | :--- |
| 🕷️ 一键召唤 | 输入 `mj` 后按回车，蜘蛛侠出现在屏幕正上方 |
| 🎬 透明动画 | 透明背景、置顶悬浮、带声音播放 |
| 🔁 常驻重播 | 无论触发多少次都重播，播放中再触发从头开始 |
| 🎛️ 控制窗口 | 特效开关按钮，关闭窗口即退出程序 |
| 🖱️ 点击穿透 | 特效窗口不挡鼠标操作 |

## 🚀 快速开始

### 方式一：免安装（推荐）

从 [Releases](../../releases) 下载 exe，解压后双击 `蜘蛛侠特效.exe` 即可使用，**无需安装 Python**。

### 方式二：源码运行

需要 Python 3，安装依赖后运行：

```bash
pip install pynput pillow
python 桌面特效/蜘蛛侠桌面特效.pyw
```

## 📂 目录结构

```
桌面特效/
├── 蜘蛛侠桌面特效.pyw   # 主程序
├── frames/              # 动画帧素材
├── audio.wav            # 特效声音
├── icon.ico             # 应用图标
└── 启动脚本             # 启动/安装辅助
```

## 💡 提示

- 输入 `stopmj` 后按回车，可退出程序
- 关闭控制窗口同样会退出
