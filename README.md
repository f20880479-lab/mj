# 抖音聊天（Douyin Chat）

一个纯前端、单页的抖音风格聊天界面，双击即用，无需安装、无需联网、无需服务器。

## 使用

双击 `抖音聊天.html`，浏览器打开即可使用（单文件，所有资源已内嵌）。

## 聊天规则

- 输入 **mj**（不区分大小写）→ 自己的消息正常显示，**蜘蛛侠出现在聊天屏幕上**（出现一次后消失，带声音）
- 输入 **mj 以外的任何内容** → 对方回复 `mj`，**蜘蛛侠同样出现在屏幕上**
- 打开时聊天记录为空白

## 图标功能（点击召唤蜘蛛侠，全部使用同一份视频+声音）

| 图标 | 功能 |
| --- | --- |
| 😊 表情 | **表情包模式**：蜘蛛侠作为大贴纸弹出，播放一遍后自动关闭 |
| 📞 语音通话 | **电话模式**：来电界面（拒接/接听）→ 接听后蜘蛛侠在通话窗口播放，带计时、静音、挂断 |
| 📹 视频通话 | **视频模式**：全屏视频通话画面，蜘蛛侠循环播放，带计时、静音、挂断 |
| ⋯ 更多 | 底部菜单：蜘蛛侠表情包 / 语音通话 / 视频通话 / 清空聊天记录 |

## 效果说明

- 人物是从 `8月21日.mp4` 中按纯色背景抠图得到的**实心透明蜘蛛侠**（完全不透明、硬边、白色大眼睛完整保留、红蓝配色），以 WebP 精灵图形式内嵌在 HTML 中
- 音轨从原视频提取并内嵌，人物出现时**声音同步播放**

## 自定义

| 想改什么 | 怎么做 |
| --- | --- |
| 修改触发词 | 在 `抖音聊天.html` 中搜索 `'mj'`，替换判断处的字符串 |
| 好友昵称 / 头像 | 修改 HTML 中 header 区域的 `小宇` 和头像 emoji |
| 更换人物视频 | 用 `scripts/segment_solid.py` 重新抠图 → `scripts/make_sheet.py` 生成精灵图 → 替换 HTML 内嵌资源 |

## 文件说明

- `抖音聊天.html` — 聊天界面（全部逻辑与资源在单个文件中）
- `8月21日.mp4` — 原始视频（蜘蛛侠抠图来源）
