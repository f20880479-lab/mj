# 蜘蛛侠桌面特效（Spiderman Desktop Effect）

一个 Windows 桌面小应用：全局监听键盘，输入 `mj` 后按回车，屏幕正上方弹出透明蜘蛛侠动画（带声音），播放完自动消失。应用常驻后台，可反复触发。

## 功能

- 输入 `mj` 后按**回车**，蜘蛛侠从屏幕正上方播放（透明背景、置顶悬浮、带声音）
- 常驻生效：无论触发多少次都会重播，播放中再次触发会从头开始
- 控制窗口：特效开关按钮，关闭窗口即退出程序
- 特效窗口点击穿透，不挡鼠标操作
- 输入 `stopmj` 后按回车 → 退出程序

## 使用

### 免安装（推荐）

从 [Releases](../../releases) 下载 exe，解压后双击 `蜘蛛侠特效.exe` 即可使用，无需安装 Python。

### 源码运行

需要 Python 3，安装依赖后运行：

```bash
pip install pynput pillow
python 桌面特效/蜘蛛侠桌面特效.pyw
```

## 目录

- `桌面特效/` — 源码（主程序、动画帧、音频、图标、启动脚本）
