# 抖音聊天（Douyin Chat）

一个纯前端、单页的抖音风格聊天界面，双击即用，无需安装、无需联网、无需服务器。

## 使用

双击 `抖音聊天.html`，浏览器打开即可使用（单文件，所有资源已内嵌）。

## 规则

- 输入 **mj**（不区分大小写）→ 自己的消息正常显示，**视频中抠出来的人物出现在屏幕上**（出现一次后消失）
- 输入 **mj 以外的任何内容** → 对方回复 `mj`，**人物同样出现在屏幕上**
- 打开时聊天记录为空白

## 效果说明

- 人物是从 `8月21日.mp4` 中按纯色背景抠图得到的**实心透明人物**（完全不透明、硬边），以精灵图形式内嵌在 HTML 中
- 出现时人物会完整播放"出现 → 亮相 → 消失"的过程，然后整体淡出

## 自定义

| 想改什么 | 怎么做 |
| --- | --- |
| 修改触发词 | 在 `抖音聊天.html` 中搜索 `'mj'`，替换判断处的字符串 |
| 好友昵称 / 头像 | 修改 HTML 中 header 区域的 `小宇` 和头像 emoji |
| 更换人物视频 | 用 `scripts/segment_solid.py` 重新抠图 → `scripts/make_sheet.py` 生成精灵图 → 重新嵌入 HTML |

## 文件说明

- `抖音聊天.html` — 聊天界面（全部逻辑与资源在单个文件中）
- `8月21日.mp4` — 原始视频（人物抠图来源）
- `scripts/` — 抠图与精灵图生成脚本（中间产物，不进 GitHub 打包）
