# 抖音聊天（Douyin Chat）

一个纯前端、单页的抖音风格聊天界面，双击即用，无需安装、无需联网、无需服务器。

## 使用

1. 把 `抖音聊天.html` 和 `8月21日.mp4` 放在**同一个文件夹**里
2. 双击 `抖音聊天.html`，浏览器打开即可使用

## 规则

- 输入 **mj**（不区分大小写）→ 自己的消息正常显示，对方发来视频消息并自动播放
- 输入 **mj 以外的任何内容** → 对方回复 `mj`
- 打开时聊天记录为空白

## 自定义

| 想改什么 | 怎么做 |
| --- | --- |
| 换成自己的视频 | 把 `8月21日.mp4` 替换成同名文件即可（也可在 HTML 中修改 `VIDEO_SRC`） |
| 修改触发词 | 在 `抖音聊天.html` 中搜索 `'mj'`，替换判断处的字符串 |
| 好友昵称 / 头像 | 修改 HTML 中 header 区域的 `小宇` 和头像 emoji |

## 文件说明

- `抖音聊天.html` — 聊天界面（全部逻辑在单个文件中）
- `8月21日.mp4` — 对方发送的视频
