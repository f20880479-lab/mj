蜘蛛侠桌面特效 · 使用说明
============================

功能
----
全局监听键盘输入：无论你在哪个软件里打字，一旦打出 mj（不区分大小写），
屏幕中央就会播放一次"透明蜘蛛侠"视频特效（带声音），播放完自动消失。
特效窗口点击穿透，不挡鼠标操作。

使用方法
--------
方式一（exe 免安装，推荐）：进入 dist\蜘蛛侠特效\ 文件夹，双击「蜘蛛侠特效.exe」即可，
无需安装 Python 和任何依赖。请保持整个 dist\蜘蛛侠特效\ 文件夹完整（含 _internal 子目录）。

方式二（源码运行）：
1. 首次使用：双击「安装依赖.bat」（只需一次，会装 pynput + pillow）
2. 以后使用：双击「启动特效.bat」→ 弹出提示即已启动

两种方式相同：
3. 在任何地方输入 mj 后按回车（Enter）→ 蜘蛛侠出现在屏幕正上方（透明背景、置顶悬浮、带声音，约 2.8 秒）
   ——必须按回车才生效；无论触发多少次都会重新播放，播放中再次触发会先清掉旧画面声音再从头播
4. 输入 stopmj 后按回车 → 退出特效程序

说明
----
- 常驻内存约 30MB（轻量），只在后台监听键盘，不记录、不保存任何输入内容
- 特效播放约 2.8 秒（166 帧 @60fps），与声音同步；播放期间再次输入 mj 不会重复触发（有冷却）
- 依赖：Python 3 + pynput + pillow(PIL) + 系统自带 tkinter
  （安装依赖.bat 已包含 pillow）

文件
----
蜘蛛侠桌面特效.pyw  主程序
frames\             动画帧（f0012.png ~ f0177.png，共 166 张透明 PNG，约 22MB）
audio.wav           特效声音（约 2.75 秒，与动画同步）
启动特效.bat        启动入口
安装依赖.bat        首次安装依赖
effect.log          运行日志（app started / effect trigger）

注意
----
- 请保持 frames 文件夹与主程序在同一目录，不要单独移动
- 更新版本后请先退出旧的特效程序（输入 stopmj 或结束旧进程）再启动新的，
  否则单实例保护会让新程序直接退出
